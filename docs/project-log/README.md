# 项目计划与执行记录

这个目录用于保留每一轮工作的计划、实际执行、验证结果和项目改动，便于日后按时间回看版本演进。

## 使用规则

1. 每次开始一项可见的开发工作前，新建一份记录：`YYYY-MM-DD-主题.md`。
2. 先填写“计划”，完成后补全“实际执行”“改动清单”和“验证结果”。
3. 一轮工作若包含多个独立功能，可在同一份记录中分小节；若跨天或目标改变，则新建记录。
4. 已完成的记录不覆盖历史内容；后续修正另开一份记录，并链接到原记录。

## 文件命名示例

```text
2026-08-25-移动端相机接入.md
2026-08-27-风险提醒规则优化.md
```

## 记录内容

复制 [模板](TEMPLATE.md) 创建新记录。每份记录应至少说明：

- 想解决什么问题、范围和不做什么；
- 实际改了哪些文件、为何修改；
- 用什么方式验证、结果如何；
- 已知限制、风险和下一步。

> 说明：这里记录的是工程工作过程；正式的架构原则与长期决策仍放在 `docs/architecture.md` 和 `docs/decisions.md`。
